# Favorite games (Wolf)

A curated list of the games marked as favorites in RetroArch and ES-DE. Kept here so they are easy to add or remove later: edit this file and ask for it to be reapplied.

This is a personal preference list, not a library inventory: a game can be here with no ROM (any longer) in `roms/<system>/`, and the library can hold far more games than are listed. No "X of Y" counting: the value is the selection, not the size of the catalog.

It covers the systems present in `retro/roms/`, including those with no ROM or no favorite yet, so the documentation stays complete and ready to fill in. **Deliberate exception**: `gb` and `gbc` are out of scope (GC, N64, NES and SNES already cover the Nintendo side well enough here), so those two folders are not documented even if they get ROMs later, unless that decision is revisited.

**Systems, and the games inside each section, are in alphabetical order** (a leading "The", "A" or "An" is ignored when sorting but kept in the text).
